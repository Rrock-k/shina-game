# 🎮 Карта Шины

Одностраничная визуализация поездок Шины по городу. В основе — PIXI.js и набор внутриигровых менеджеров, отвечающих за время, маршруты, освещение и UI. Проект запускается как статический сайт, поэтому никаких серверов или WebSocket-слоёв сейчас не нужно.

## 🚀 Как запустить

> Требуется Python 3 (для простого статического хоста). Если удобнее, откройте `index.html` напрямую — большинство браузеров работают без дополнительных шагов.

```bash
# из корневой директории
python3 -m http.server 8000
# затем откройте http://localhost:8000/index.html
```

Для удобства есть npm-скрипты-обёртки (выполняют ту же команду):

```bash
npm run dev   # python3 -m http.server 8000
npm run start # то же самое
```

## 🧭 Что внутри

```
shina-game/
├── index.html            # Точка входа и разметка UI
├── public/               # CSS и ассеты
├── src/
│   ├── config/           # Конфигурации карт и расписаний
│   ├── entities/         # Логика сущностей (машина, Шина, состояния)
│   ├── game/             # Менеджеры времени, расписания, основная игра
│   ├── rendering/        # PIXI-рендереры
│   ├── systems/          # Системы движения, светофоры, панорамирование
│   └── utils/            # Геометрия, математика, хранилище
└── docs/                 # Актуальная документация проекта
```

## 🎯 Текущие возможности

- Отрисовка города и маршрутов на PIXI.js.
- Система игрового времени с ускоренными циклами дня и ночи.
- Менеджеры расписаний и состояний Шины (сон, работа, поездки).
- Светофоры, панорамирование карты и простое управление через UI.

## 🧪 Скрипты для обслуживания

```bash
npm run manage   # интерактивное меню утилит
npm run collect  # собрать содержимое репозитория в один файл (без node_modules)
```
