# Текущее состояние проекта

Обновлено: 2024‑12‑19

## Основная идея

«Карта Шины» — статичная PIXI.js‑визуализация, где игрушечная машина катает персонажа по городу по внутреннему расписанию. Всё работает на стороне клиента: данные берутся из `src/config`, логика живёт в менеджерах внутри `src/game`, отрисовка — в `src/rendering`.

## Что уже есть

| Блок                | Что делает                                                                 |
|---------------------|----------------------------------------------------------------------------|
| `Game.js`           | Точка сборки: создаёт PIXI‑сцену, менеджеры времени/расписаний, UI         |
| `TimeManager`       | Игровые сутки с ускорением, переключение дня/ночи                          |
| `ScheduleManager`   | Дневное расписание задач, динамический выбор следующей локации             |
| `Car` + `MovementController` | Маршруты по сетке дорог, светофоры, плавный переход между сегментами |
| `Shina` + `StateMachine`     | Состояния (сон/работа/ожидание), приоритеты «усталость/друзья»        |
| `WorldRenderer`     | Построение карты города, зон, слоёв PIXI                                    |
| `UIRenderer`        | Меню, журнал поездок, расписание, кнопки скорости/паузы                     |

## Технические детали

- **Рендеринг**: PIXI.js 7.x, фиксированное поле 1200×800 с панорамированием и зумом.
- **Архитектура**: ES‑модули, независимые менеджеры и рендереры, конфигурирование через `CONFIG`.
- **Запуск**: статический сайт, достаточно `python3 -m http.server 8000`.

## Что нужно держать в голове

- Движение машины и построение маршрутов читают данные из `ScheduleManager`; `CONFIG.ROUTE_SCHEDULE` остался только как запасной шаблон на случай пустого планировщика.
- Документация в `docs/` отражает актуальные решения; старые архивы удалены.
