# Документация «Карты Шины»

Минимальный набор файлов, которые действительно отражают текущее состояние проекта. Архивы и старые планы удалены — всё то, что лежит здесь, поддерживаем актуальным.

## 📚 Что почитать

- `architecture.md` — концепция игры, ключевые сущности и общая логика.
- `current-state.md` — свежее описание того, что работает сейчас.
- `final-architecture.md` — целевая архитектура, к которой двигаемся.
- `layer-structure.md` — объяснение PIXI-слоёв и порядок отрисовки.
- `tech-debt.md` — активный технический долг и планы на починку.
- `todo.md` — короткое напоминание об идее проекта.

Документов за пределами этого списка нет — всё лишнее вычищено. Если появится новый план или исследование, добавляйте отдельным файлом и следите за актуальностью.
